# TG WS Proxy для Android

Android-версия локального MTProto-прокси **Flowseal/tg-ws-proxy**.
Прокси работает на самом телефоне (`127.0.0.1:1443`), и только Telegram ходит через него.
VPN не нужен, банки и маркетплейсы работают как обычно.

Внутри приложения лежит оригинальное ядро Flowseal (папка `app/src/main/python/proxy`, версия 1.11.2, лицензия MIT),
запущенное через Chaquopy. Android-часть добавляет:

- **foreground-службу** с постоянным уведомлением, поэтому Android не выгружает прокси из памяти;
- **автоперезапуск**, если прокси упал, и **перезапуск при смене сети** (Wi-Fi ↔ мобильный интернет);
- **автозапуск после перезагрузки** телефона;
- кнопки «подключить Telegram», «копировать ссылку», «разрешить работу в фоне», «показать лог».

## Как получить APK (без Android Studio, всё в браузере)

1. Зайдите на github.com (можно через Google) и создайте **новый репозиторий** (кнопка `+` → New repository), например `tg-ws-proxy-android`. Приватный подойдёт.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки
   (включая скрытую папку `.github`). Нажмите **Commit changes**.
3. Откройте вкладку **Actions**. Сборка запустится сама (3–8 минут). Если не запустилась: Actions → *Build APK* → **Run workflow**.
4. Когда появится зелёная галочка, откройте запуск и внизу в разделе **Artifacts** скачайте `TgWsProxy-apk` (zip).
5. Распакуйте, перекиньте `app-release.apk` на телефон и установите (разрешите установку из неизвестных источников).

> Если сборка красная — откройте её лог и пришлите мне текст ошибки, я исправлю.

## Первый запуск на телефоне

1. Откройте **TG WS Proxy**, разрешите уведомления.
2. Нажмите **«1. Подключить Telegram»**. Откроется Telegram с предложением добавить прокси, нажмите «Подключить прокси».
3. Нажмите **«2. Разрешить работу в фоне»** и выберите «Разрешить».
4. На Xiaomi / Huawei / Honor / OPPO / Realme / Vivo дополнительно: включите приложению **«Автозапуск»** и закрепите его в списке недавних (замочек).
5. Выключите VPN. Telegram должен работать через прокси.

## Если Telegram не грузит фото и видео

См. раздел «Не грузит фото/видео?» в оригинальном README Flowseal: это связано с тем, как Telegram выбирает дата-центры
для аккаунтов без Premium. Настройки прокси (DC → IP, свой Cloudflare-домен) лежат в `app/src/main/python/android_entry.py`
и в `Prefs.kt` (`DC_IPS`).

## Структура

```
app/src/main/java/app/tgwsproxy/   Kotlin: экран, служба, автозапуск
app/src/main/python/android_entry.py   запуск/остановка ядра Flowseal
app/src/main/python/proxy/             ядро Flowseal (без изменений)
.github/workflows/build.yml        сборка APK в GitHub Actions
```
